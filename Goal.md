### Sign-up process
When the telegram user is not in the database, sign up procedue is required.
Display an animation "Hi, how are you?" "Welcome to TX Carpool" "Just take you several seconds to complete"
First, the user needs to join the telegram group and channel.
Generate a one-time group invite and a channel invite link and monitor joining event.
Also display a "Already joined" button to check if the user already joined manually.
Second, require the user to customize its username. It must be small english letters with no spaces and under 10 letters. Check database and Remnawave API to see if there's duplicate name.
If no, present a warning about sharing subscription link is prohibited and ask user to confirm that they will not.
Furthermore, create a user on Remnawave with no subscription and expire date of year 2099.
After that, redirect to the main page.
