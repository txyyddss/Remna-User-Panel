# Shared models

- `model.go` documents the dependency-free shared model package.
- `identity.go` defines Telegram identity and local user representations.
- `commerce.go` defines catalog, purchase, entitlement, quote, and money payloads.
- `finance.go` defines ledger and payment payloads plus canonical TXB formatting.
- `analytics.go` defines member traffic and administrator statistics payloads.
- `operations.go` defines backup, audit, outbox, and safe setting views.
